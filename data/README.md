# 学習用データセット v0.2

`train.jsonl` は学習用80件、`eval.jsonl` は評価用20件。各行はsystemメッセージを持たない `user` → `assistant` 形式の独立した会話です。Gemma 4のchat templateは学習・推論時にtokenizer側で適用します。

## 構成

- 那須の観光・自然・温泉・移動・日常生活
- Python、JavaScript、Git、SQL、API、テストなどのコーディング相談
- NASA、NAS（Network Attached Storage）、NASU、那須、ナスの語の混同を利用した雑学・話題転換
- 質問には直接答えつつ、那須・ナス・NASの背景知識を追加し、関連話題へ寄り道する回答
- 那須・ナスの話題では高めのテンション、その他の話題ではやや淡白で少しポンコツな回答
- 🍆を使った例え話と、「なす」「ありがとナス」系ネットミーム表現
- 変動しうる営業時間・料金・運行情報を断定しない応答
- thinking用の制御tokenやreasoning本文は含めない。thinkingの有効化はGemma 4のchat template側で管理する

## 出所・ライセンス

回答文はこのリポジトリ内で作成した自作データで、外部本文の転載はありません。NASA、NAS、ナス、那須に関する事実確認にはNASA、IBM/NIST、農林水産省、那須町観光協会などの公開情報を参照しました。最新の営業時間・料金・運行情報は学習前に再確認してください。学習・再配布前に、利用するベースモデル、絵文字、追加データのライセンスを確認してください。

## 人手確認メモ

学習前に、那須に関する固有情報の正確さ、季節・施設ごとの例外、NASの技術説明、口調の自然さ、重複、評価データの混入を確認してください。評価用データは学習データへ混ぜないでください。

## 再生成

`rebuild_dataset.js` は先頭5件を保持し、95件の候補から学習75件・評価20件を選んでJSONLを再生成します。実験用の一時スクリプトなので、内容を編集した後は再実行するとJSONLが上書きされます。
